# curettu / portfolio

Личное портфолио Асанали, который в интернете использует ник `curettu`.

На главной странице собраны профиль, статистика и актуальные публичные репозитории из GitHub API. Страница About рассказывает немного обо мне и ведёт к моим соцсетям через Linktree.

## Структура

- `Main_Page/` — главная страница и список проектов.
- `About/` — информация обо мне и социальные ссылки.
- `gh_api/` — общий клиент публичного GitHub API.

Проект написан на HTML, CSS и TypeScript. Для публикации достаточно отдавать корень проекта через статический сервер после компиляции TypeScript.
